# Glen Canopies Wireframes

This folder contains a low-fidelity wireframe pack of the site as it currently stands.

Files:

- `glen-canopies-wireframes.svg`

How to use it in Canva:

1. Open Canva.
2. Upload `glen-canopies-wireframes.svg`.
3. Place it on a design canvas.
4. Ungroup the SVG elements so you can edit the sections, labels, spacing, and page blocks.

What is included:

- Home
- About & Services
- Service Detail template
- Recent Work archive
- Project Detail
- Developments
- Contact
- FAQ

Notes:

- These are structural wireframes, not visual mockups.
- They reflect the current live section order and content hierarchy.
- The contact frame includes an extra placeholder zone near the bottom in case you want to add more support content inside Canva.
- If you want, a second pass can be created for:
  - mobile wireframes
  - homepage-only high-detail wireframes
  - a sitemap / internal-linking diagram
  - editable Figma-style grayscale component sheets
